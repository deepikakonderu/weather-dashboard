# ☁ Weather Dashboard

A modern and responsive Weather Dashboard built using HTML, CSS, and JavaScript.

## 🚀 Live Demo

https://weather-dashboard-three-jet.vercel.app

---

## ✨ Features

- 🌍 Worldwide city weather search
- 🌡 Real-time temperature updates
- 💧 Humidity tracking
- 🌬 Wind speed information
- ☁ Dynamic weather conditions
- 🎨 Modern glassmorphism UI
- 📱 Fully responsive design
- ⚡ Fast API integration using async/await

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Open-Meteo API
- Font Awesome
